# 精度と時間の実験（MetricAnything）

> **このドキュメントで決めたこと**
> 1. 12枚の写真（手の甲10枚・手のひら2枚）で、正解（写真1の Depth Pro の値＝本人が定規で確かめた値）とのずれと、補正後のずれを出す。合格の目安は、補正後の中央値 ±2%・最大 ±4%。
> 2. 写真ごとに、途中経過と結果の画像を出す（§1）。結果の画像は長い辺 1280px で描き、文字を読めるようにする。
> 3. 写真1枚ごとの段階別の時間と、その中央値を表にする。
