# しくみと方法（YOLO26 Depth）

> **このドキュメントで決めたこと**
> 1. YOLO26 Depth の距離（m）と、焦点距離（px）から、手首と指の付け根の5点を3Dに直して長さを出す（Depth Pro と同じ式）。YOLO26 Depth は焦点距離を出さないので、出どころを4つ比べる（§2）。
> 2. モデルは一番大きい `yolo26x-depth` と一番小さい `yolo26n-depth` を中心に、5つの大きさを全部試す。画像は公式の推奨どおり `imgsz=768`（正方形に引き伸ばして推論し、元の大きさに戻す）。
> 3. 補正は「ずれの平均で割る」形で、**1枚を除いた残りで補正値を作り、除いた1枚に当てはめる**確かめで評価する（§4）。基準は本人が定規で確かめた手の長さで、Depth Pro の出力を本番の計算には使わない。

関連：[README.md](README.md)、[scripts.md](scripts.md)

---

## 1. 使い方（配布物 `ultralytics` 8.4.207 で確かめた、2026-11-08）

```python
from ultralytics import YOLO
model = YOLO("yolo26x-depth.pt")
r = model(画像, imgsz=768)[0]
depth_m = r.depth.data.cpu().numpy()   # (H, W)、メートル、入力の画像と同じ大きさ（公式のドキュメント）
```

- 重みは公式の配布元から取る。置き場所は `experiments/depth_scale_yolo26/checkpoints/`（コミットしない）
- 出力の大きさが入力と違う場合は、元の画像の大きさに引き伸ばす

## 2. 焦点距離の出どころ

大きさは「距離 ÷ 焦点距離」で決まるので、焦点距離がずれると、長さも同じ割合でずれる。

| 名前 | 出どころ | 本番で使えるか | ねらい |
|---|---|---|---|
| `exif` | 写真の撮影情報（35mm 換算の焦点距離）から計算 | 写真のファイルなら使える場合がある（ブラウザのカメラの映像には残らない） | **焦点距離が正しいときの、YOLO26 Depth の距離そのものの精度**。追加の10枚だけ |
| `depthpro` | Depth Pro が推定した焦点距離 | 使えない（研究目的だけ） | 物差し。写真1・写真2を含む全部 |
| `fixed26` | 「スマホの広角は 35mm 換算 26mm」と決め打ち | **使える** | 本番で一番現実的。機種による違い（24〜28mm）がどれだけ効くか |
| `moge2` | MoGe-2（MIT）が推定した焦点距離 | 使える | 推定した焦点距離の精度 |

### 2.1 撮影情報から焦点距離を出すときの注意

35mm 換算の焦点距離は、**撮像素子の全体（切り取る前の画像）**の対角線を 43.27mm とみなした値。追加の写真のうち8枚（2268×4032）は、元の 3024×4032（縦横 3:4）から**左右を切り取ったもの**なので、切り取ったあとの画像の対角線で計算すると約8%ずれる。そこで：

```
切り取る前の大きさ：長い辺はそのまま、短い辺 = 長い辺 × 3/4（iPhone の広角は 4:3）
f_px（元の画像）= 35mm 換算 × √(長い辺² + 短い辺²) ÷ 43.27
縮めた画像では、縮めた割合を掛ける
```

例：長い辺 4032px、26mm → 約 3028px。長い辺を 1280px に縮めると約 961px。

## 3. 長さの出し方

1. 写真を、撮影情報の向きどおりに回して読み、長い辺 1280px まで縮める（ほかの実験と同じ）
2. MediaPipe で手の21点を出す
3. YOLO26 Depth で距離（mm）を出し、5点のまわり（半径 3px）の中央値を取る
4. 焦点距離（出どころごと）で3Dに直し（`X = (u − cx) × Z ÷ f`）、4区間の長さを出す
5. 正解とのずれ（4区間の比の中央値）を出す

- **手のひらを上にした写真（IMG_6509・6510）**は、手首と付け根の点の取られ方が手の甲と違うので、表では分けて示し、補正の評価からは除いた場合も出す

## 4. 補正の評価

1. 写真 i ごとに、ずれの比 `r_i = median(長さ ÷ 正解)` を出す（モデル × 焦点距離の出どころごと）
2. 写真 i を除いた残りの写真の比の平均 `c_i` を出し、写真 i の長さを `c_i` で割る（1枚を除く確かめ）
3. 補正後のずれの、絶対値の中央値と最大を出す
4. **合格の目安：補正後のずれの中央値 ±2% 以内・最大 ±4% 以内**
5. 比べるのは、YOLO26 Depth（5つの大きさ × 焦点距離の出どころ）と、これまでのモデル（Depth Anything 3・MoGe-2・MapAnything）。これまでのモデルも、追加の10枚で動かす
