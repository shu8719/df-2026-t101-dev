# YOLO26 Depth で手を実寸にする（1円玉がないとき）

> **このドキュメントで決めたこと**
> 1. Ultralytics の **YOLO26 Depth**（AGPL-3.0）で、写真から手の甲の4区間の長さ（mm）を出せるかを確かめる。距離は m で出すが焦点距離は出さないので、**焦点距離の出どころを変えて**比べる（写真の撮影情報 EXIF・Depth Pro・MoGe-2・「スマホは 26mm 相当」と決め打ち）。
> 2. 写真は12枚（写真1・写真2と、追加の10枚 IMG_6501〜6511）。正解は写真1の Depth Pro の値（本人が定規で確かめた値）。追加の10枚には撮影情報（iPhone 14、35mm 換算 26mm）が残っているので、焦点距離の正解も分かる。
> 3. あわせて、**ずれの平均で直す補正**（[../depth-scale/comparison.md §5](../depth-scale/comparison.md#5-補正値の案)）を、YOLO26 Depth とこれまでのモデルで、12枚・1枚を除く確かめで評価する。MVP には入れず、本番のコードは変えない。

## なぜ YOLO26 Depth か

| 項目 | 中身 |
|---|---|
| 作った所・年 | Ultralytics・2026年（`yolo26n〜x-depth` の5つの大きさ） |
| ライセンス | **AGPL-3.0**（`ultralytics` 8.4.207 の配布物の表示）。商用も可。ただし、使ったソフトを人に使わせる（ネットのサービスを含む）なら、そのソースコードも公開する。提出用のリポジトリは公開なので、守りやすい |
| 出すもの | 各画素の距離（m）。焦点距離は出さない（入力にも使わない） |
| 補正の仕組み | 公式に `model.calibrate()` がある（距離全体を `d' = exp(a·log d + b)` で直す。正解の距離つきの写真が要る） |
| 学習 | 部屋と屋外を混ぜた約219万枚。0.02〜150m の距離を扱う（公式のドキュメント） |
