# 精度の実験（YOLO26 Depth と補正）

> **このドキュメントで決めたこと**
> 1. 12枚の写真で、YOLO26 Depth（5つの大きさ × 焦点距離の出どころ）と、これまでのモデルのずれを出す。正解は写真1の Depth Pro の値（本人が定規で確かめた値）。
> 2. 写真ごとに途中経過と結果の画像を出す（§2）。全体のまとめとして、ずれの散らばりのグラフと、補正前後の表を出す。
> 3. 補正（ずれの平均で割る）を1枚を除く確かめで評価し、合格の目安（中央値 ±2%・最大 ±4%）に入る組み合わせがあるかを決める。

関連：[README.md](README.md)、[method.md](method.md)
