# 精度の実験（YOLO26 Depth と補正）

> **このドキュメントで決めたこと**
> 1. 12枚の写真で、YOLO26 Depth（5つの大きさ × 焦点距離の出どころ）と、これまでのモデルのずれを出す。正解は写真1の Depth Pro の値（本人が定規で確かめた値）。
> 2. 写真ごとに途中経過と結果の画像を出す（§2）。全体のまとめとして、ずれの散らばりのグラフと、補正前後の表を出す。
> 3. 補正（ずれの平均で割る）を1枚を除く確かめで評価し、合格の目安（中央値 ±2%・最大 ±4%）に入る組み合わせがあるかを決める。

関連：[README.md](README.md)、[method.md](method.md)

## 4. 決めたこと

- **補正（ずれの平均で直す）で、合格の目安（中央値 ±2%・最大 ±4%）に入る組み合わせはなかった**
- **本番で使えるライセンスで一番良いのは「DA3 ＋ 補正」**：DA3 はいつも大きめ（+10〜+50%）に外れるが、その向きがそろっているので、補正で中央値 6.5%（焦点距離 MoGe-2）〜4.2%（焦点距離 Depth Pro）まで下がる。ただし最大は 18〜20%
- **YOLO26 Depth は、写真ごとのずれ方がばらばら**で、補正しても中央値 10% 前後。一番小さい n は大きく外れる
- **Depth Pro 自身も、手の甲の10枚では中央値 5.1%・最大 16%**（写真1・写真2の2枚だけのときより悪い）。外れが大きいのは、指を曲げた写真（6511 +16%）や模様の上（6503 −12%）。指を曲げると MediaPipe の付け根の点がずれやすいことも効いている見込み（距離の推定だけの誤差ではない）
- 1円玉の方法（本番）の検証の目標は ±3mm（[measurement.md §10.1](../measurement.md#101-測るものと道具)、手の甲で約 ±4〜5%）。これに照らすと、**DA3 ＋ 補正（中央値 4〜7%）は「中央値ではあと一歩、外れる写真がある」**という位置
- 次の手：①1枚ではなく動画の複数のフレームの中央値で、写真ごとのばらつきを減らせるか、②Metric3D v2 を撮影情報の正しい焦点距離で試す、③別の人の手で、同じ補正値が効くか
