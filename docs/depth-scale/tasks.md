## 3. ライセンスで分かったこと（DS1、2026-11-07）

Depth Pro（[github.com/apple/ml-depth-pro](https://github.com/apple/ml-depth-pro)・[huggingface.co/apple/DepthPro](https://huggingface.co/apple/DepthPro)）を読んで分かったこと。

| 対象 | 分かったこと | 状態 |
|---|---|---|
| コード | Apple 独自のライセンス（MIT や Apache ではない）。使う・直す・配ることを認めている。「研究だけ」「商用は不可」の制限は見つからなかった。条件は、そのまま配るときに著作権の表示を残すこと、Apple の名前を宣伝に使わないこと。特許の権利は認めていない。ほかのライブラリの部分は `ACKNOWLEDGEMENTS` に別の条件がある（未確認） | ほぼ確認済み |
| 重み | Hugging Face の `LICENSE` は「Apple Machine Learning Research Model License Agreement」（`apple-amlr`）。使えるのは「研究目的（Research Purposes）だけ」で、研究目的は「非営利の科学研究や学術的な開発」（例：実験・分析・テスト）。「製品の開発や、商用の製品・サービスでの利用は含まない」。違反すると Apple は許可を取り消せ、そのときは使用をやめて重みを消す。ダウンロードの前の同意の画面はなく、使った時点で同意したことになる | 確認済み（2026-11-07） |
| 配り方 | 重みはリポジトリにもイメージにも入れず、使う人が自分で取ってくる形にする | 決めた |

**決めたこと（2026-11-07）**：

- Depth Pro は、**手元のPCで精度を測る実験（研究目的の実験・分析）だけ**に使う。重みは `experiments/depth_scale/checkpoints/` に置き、`.gitignore` に入れてコミットしない
- **アプリ（本番・審査・デモ）には組み込まない**。製品の開発と見なされるおそれが強いため。実験で精度が足りても、本番に入れるなら、商用でも使えるライセンスの別のモデルを探す（[§4](#4-採用することになったら)）
- 実験で Depth Pro を使ったことは、発表資料と著作物利用シートに書く（「Depth Pro（Apple、Apple Machine Learning Research Model License）」）
