# 精度の実験（MoGe-2）

> **このドキュメントで決めたこと**
> 1. 手順・比べる条件（A・B・C）・比べ方・合格の目安は、Depth Pro の実験（[../depth-scale/experiment.md](../depth-scale/experiment.md)）と同じにする。違うのは、③深度の推定のモデルだけ。
> 2. **同じ動画・同じフレーム・同じ手の21点**で、ノギス・1円玉・Depth Pro・MoGe-2（大きい版・小さい版）を1つの表に並べる。
> 3. 写真1枚の手軽な確かめ（`try_image.py`）でも、Depth Pro と MoGe-2 を同じ写真で並べる。

関連：[README.md](README.md)、[method.md](method.md)、[scripts.md](scripts.md)

---

## 1. 手順

[Depth Pro の実験の §1・§2](../depth-scale/experiment.md#1-用意するもの) と同じ。撮影とノギスは1回だけ行い、両方の実験に使う。

## 2. 比べる条件

| 条件 | 中身 | MoGe-2 での扱い |
|---|---|---|
| A 全体・焦点距離もAI | フレームそのまま | 画角を与えずに推定させる |
| B 切り抜き・焦点距離もAI | 本番で `hand-mesh` に送るのと同じ切り抜き（長い辺512px） | 画角を与えずに推定させる。焦点距離は元のフレームの px に直す |
| C 焦点距離を与える | フレームそのまま | 機種の焦点距離から水平の画角 `fov_x`（度）を計算して与える |

- 長さは、点群から出したもの（[method.md §2.1](method.md#21-点のまわりの3d位置)）を本命にする。深度とカメラの情報から出したもの（§2.2）は確かめ用として並べる
- モデルは大きい版（`vitl`）と小さい版（`vits`）の2つ

## 3. 合格の目安

[Depth Pro の実験の §5](../depth-scale/experiment.md#5-合格の目安) と同じ。ずれの絶対値が、中央値で2%以内、最大で4%以内、同じ人の3回のばらつきが2%以内。

## 4. 結果

### 4.1 写真1枚の確かめ（`try_image.py`）

| 写真 | 区間 | ノギス | Depth Pro | MoGe-2（vitl） | MoGe-2（vits） |
|---|---|---|---|---|---|
| 写真1（開いた手、手の甲を上、904×1280px に縮めた） | 0→5 | （未測定） | 75.5mm | 136.0mm | 123.4mm |
| | 0→9 | | 72.3mm | 135.8mm | 124.3mm |
| | 0→17 | | 69.3mm | 121.9mm | 126.4mm |
| | 5→17 | | 61.8mm | 113.5mm | （記録漏れ） |
| | カメラから手首まで | （未測定） | 221mm | 416mm | 362mm |
| | 焦点距離（px） | — | 1079px | 1069px | 1230px |
| | 1枚の推論の時間 | — | 1.0秒 | 5.1秒 | 1.3秒 |
| | 点群と深度の長さの差 | — | — | 0.20% | 0.15% |

2026-11-08 に、RTX 3080 Ti Laptop で測った。半径 3px、深度に足した量 0mm。

**分かったこと**：

- MoGe-2 の長さは、Depth Pro の約1.8倍（vitl で 1.76〜1.88倍、区間によらずほぼ一定）。大人の手の「人差し指の付け根〜小指の付け根」（関節の中心どうし）が 113mm はありえないので、**MoGe-2 の実際の大きさの推定（倍率）が、この近さの手では大きく外れている**と見られる。Depth Pro の値の方が大人の手として自然（ただしノギスとの比較はまだ）
- 計算の誤りではない：点群と深度からの長さの差が 0.2% 以内なので、px の焦点距離への直し方は正しい。単位の読み違いなら1000倍ずれるはずで、それとも違う
- 焦点距離は Depth Pro とほぼ同じ（vitl で差1%）。外れているのは距離（倍率）だけ
- 形は良い：区間どうしの比は Depth Pro とほぼ同じ。面の向きの画像で指と関節の凹凸がきれいに出ていて、使えない画素もない
- **次の案**：MoGe-2（MIT）の焦点距離を、`DA3METRIC-LARGE`（Apache-2.0。焦点距離を与えると「焦点距離 × 出力 ÷ 300」で実際の深度を出す）に与える組み合わせを試す。どちらも本番で使えるライセンス
