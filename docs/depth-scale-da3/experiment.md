# 精度の実験（Depth Anything 3）

> **このドキュメントで決めたこと**
> 1. まず**写真1枚**（Depth Pro が正確だった写真）で、[method.md §3](method.md#3-試す組み合わせ) の4つの組み合わせを Depth Pro・MoGe-2 と並べる。①（Depth Pro の焦点距離）で DA3 の深度そのものが合うかを先に確かめる。
> 2. 写真1枚で②が Depth Pro に近ければ、動画での比較（手順・条件・合格の目安は [Depth Pro の実験](../depth-scale/experiment.md) と同じ）に進む。
> 3. 正解は、本人が定規・ノギスで測った手の甲の4区間の長さ。数値を §3.1 に記録する。

関連：[README.md](README.md)、[method.md](method.md)、[scripts.md](scripts.md)

---

## 1. 手順

1. Depth Pro 側と MoGe-2 側の `try_image` を、同じ写真で先に動かしておく（焦点距離と比べる数値の JSON ができる）
2. DA3 側の `try_image_da3.py` で、4つの組み合わせを出す
3. 正解（定規・ノギス）と並べて、ずれ（%）を出す
4. ②が合えば、動画で比べる（[../depth-scale/experiment.md §2](../depth-scale/experiment.md#2-手順) と同じ。撮影とノギスは1回だけ行い、全部の実験に使う）

## 2. 合格の目安

[Depth Pro の実験の §5](../depth-scale/experiment.md#5-合格の目安) と同じ。ずれの絶対値が、中央値で2%以内、最大で4%以内、同じ人の3回のばらつきが2%以内。

## 3. 結果

2026-11-08 に、RTX 3080 Ti Laptop で測った。DA3 が見た画像は 350×504px。半径 3px、深度に足した量 0mm。③の倍率は 0.689。

- 本人の確かめ（2026-11-08）：**Depth Pro はとても正確、MoGe-2 は 3〜4cm ずれていた**。区間ごとの正解の数値はまだもらっていない

**分かったこと**：

- **DA3 の深度そのものが、この近さの手では外れる**：一番条件の良い①（Depth Pro の正しい焦点距離）でも、手首までの距離が 281mm（Depth Pro は 221mm）で約27%遠く、長さは約25%大きい。[method.md §3 の判断](method.md#結果での判断) の「①が外れる」に当たる
- **DA3 では、焦点距離は長さにほとんど効かない**：②の焦点距離が 1069px でも 1230px でも、長さはほぼ同じ。DA3 の深度は「出力 × 焦点距離 ÷ 300」で、3Dに直すときに「÷ 焦点距離」をするので、横方向の長さでは焦点距離が打ち消し合う。**「MoGe-2 の正しい焦点距離を渡せば直る」という見込みは、もともと成り立たなかった**（[method.md §1](method.md#1-なぜこの組み合わせか) の考えの誤り）。DA3 の大きさは、モデル自身が決めている
- MoGe-2 単独（約+80%）よりは近いが、合格の目安（±2%）からは遠い
- 速い：2回目以降は1枚 0.1秒ほど
