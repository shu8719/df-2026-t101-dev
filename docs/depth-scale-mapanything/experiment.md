# 精度の実験（MapAnything）

> **このドキュメントで決めたこと**
> 1. 写真1（キーボードあり）と写真2（無地の紙）で、MapAnything の手の甲の4区間を出し、正解（写真1の Depth Pro の値）と比べる。合格の目安は、ずれの中央値 ±2% 以内・最大 ±4% 以内。
> 2. 途中経過を画像で残す（§2）。外れたときに、どこで外れたか（距離・焦点距離・点の位置・使えない画素）を見分けるため。
> 3. 写真1枚で合格したら、動画（本番と同じ撮り方）で確かめる。外れたら、本番で使えるモデルは今のところ見当たらないと結論づける。

関連：[README.md](README.md)、[method.md](method.md)、[scripts.md](scripts.md)

|---|---|---|---|---|

## 3. 結果

### 3.1 写真1枚

2026-11-08 に、RTX 3080 Ti Laptop で測った（重みは 4.6GB、推論は1枚 0.8〜1.2秒）。

| 区間 | 正解 | MapAnything・写真1 | ずれ | MapAnything・写真2 | ずれ |
|---|---|---|---|---|---|
| 0→5 | 75.5mm | 395.1mm | +423% | 360.0mm | +377% |
| 0→9 | 72.3mm | 380.1mm | +426% | 347.1mm | +380% |
| 0→17 | 69.3mm | 370.5mm | +435% | 310.3mm | +348% |
| 5→17 | 61.8mm | 303.4mm | +391% | 286.4mm | +363% |
| カメラから手首まで | （Depth Pro：写真1 221mm、写真2 231mm） | 1294mm | | 1251mm | |
| 焦点距離（px、元の画像） | （Depth Pro：写真1 1079px、写真2 1009px） | 約1281px | | 約1204px | |
| ずれの中央値 | | **+424%（不合格）** | | **+370%（不合格）** | |

- モデルが見た画像は、写真1で 392×518px、写真2で 294×518px（縮めて切り取ったもの）。倍率（`metric_scaling_factor`）は 1.081・0.977
- 点群と深度からの長さの差は 0.54〜0.91%（計算の誤りではない）

**途中経過の画像から分かったこと**：

- 手の点（モデルが見た画像の上）は正しい位置にあり、切り取りで手は欠けていない
- 深度の画像で手の形はきれいに分かれ、信頼度は手の甲で高く、使えない画素もほとんどない
- 点群を横から見ると、手は板のように並んでいるが、**距離が 1.2〜1.3m**（Depth Pro は約22cm）。単位の誤り（1000倍）ではなく、モデルが「1.2m 先の大きな手」と見積もっている

### 3.2 決めたこと

- **MapAnything は、手の実寸には使えない**（写真1で +424%、写真2で +370%）。形はよく出るが、大きさの見積もりが大きく外れる
- これで、本番で使えるライセンスの有力な候補（MoGe-2・Depth Anything 3・MapAnything）は、**すべて合格の目安から大きく外れた**。正確なのは研究目的だけのライセンスの Depth Pro だけ
- **結論：本番で1円玉の代わりにできるモデルは、今のところ見当たらない。** 本番は1円玉のまま進め、発表では Depth Pro の結果を「今後の方向性」として示す
