# 精度の実験（MapAnything）

> **このドキュメントで決めたこと**
> 1. 写真1（キーボードあり）と写真2（無地の紙）で、MapAnything の手の甲の4区間を出し、正解（写真1の Depth Pro の値）と比べる。合格の目安は、ずれの中央値 ±2% 以内・最大 ±4% 以内。
> 2. 途中経過を画像で残す（§2）。外れたときに、どこで外れたか（距離・焦点距離・点の位置・使えない画素）を見分けるため。
> 3. 写真1枚で合格したら、動画（本番と同じ撮り方）で確かめる。外れたら、本番で使えるモデルは今のところ見当たらないと結論づける。

関連：[README.md](README.md)、[method.md](method.md)、[scripts.md](scripts.md)

## 2. 出す途中経過の画像

保存先は `experiments/depth_scale_mapanything/data/vis/`（コミットしない）。

| 画像 | 中身 | 見たいこと |
|---|---|---|
| `_1_input` | モデルが実際に見た画像（縮めて切り取ったもの）と、MediaPipe の21点 | 切り取りで手が欠けていないか、点が合っているか |
| `_2_depth` | 深度を色で（近い＝赤、遠い＝青）、5点の距離を書き込む | 距離が正しそうか（写真1の手首は Depth Pro で 221mm） |
| `_3_conf` | 信頼度を色で | 手の部分を、モデルが自信を持って推定しているか |
| `_4_mask` | 使えない画素を赤く塗る | 手の上が除かれていないか |
| `_5_side` | 手の部分の点群を真横から見た図（横＝左右、縦＝奥行き） | 手が平らな板として、正しい奥行きに並んでいるか |
| `_6_result` | 最終の重ね描き（4区間の線と長さ、正解とのずれ%） | 結果 |
| `_grid` | 上の6枚をまとめたもの | 一目で見る |
