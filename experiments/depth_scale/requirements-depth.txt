# ③ depth.py で Depth Pro を使うときだけ入れる。

# PyTorch は hand_mesh/ と同じ版（CUDA 13.2）：
#   .venv\Scripts\python -m pip install torch==2.14.1 torchvision==0.29.1 --index-url https://download.pytorch.org/whl/cu132
#
# Depth Pro は PyPI にないので、コミットを固定して入れる（2026-11-07 の最新）：
#   .venv\Scripts\python -m pip install "git+https://github.com/apple/ml-depth-pro@9e65e4dbe9568d23c546fcec53302b10445e109e"
#
# Depth Pro は numpy<2 を指定していて、入れると numpy が 1.26 に下がる。OpenCV 5 と MediaPipe は numpy 2 以上が要るので、
# 入れたあとに numpy を戻す（pip が「depth-pro は numpy<2 が要る」と警告を出すが、2026-11-07 に numpy 2.5.4 で動くことを確かめた）：
#   .venv\Scripts\python -m pip install numpy==2.5.4
#
# 重み（depth_pro.pt、1.9GB）は checkpoints/ に置く（.gitignore に入っているのでコミットされない）：
