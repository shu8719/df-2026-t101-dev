## 1. スライドごとの中身と原稿

### スライド 1：タイトル（10 秒）

- 画面：プロダクト名（仮称「自助具ジェネレーター」）、ひとこと「こぶしを撮るだけで、自分の手に合う自助具を」、チーム名、刷ったカバーの写真
- 原稿：
  > 「チーム○○です。スマホでこぶしを撮るだけで、その人の手に合う自助具を 3D プリントできる Web アプリを作りました。」

### スライド 2：課題（35 秒）

- 画面：
  - 握った形で指が固まった手の図（写真は使わない。イラスト）
  - 「筆・ペン・スプーンが持てない」
  - 数字：**3D プリンタを使ったことがある作業療法士は 4.4%**（3,469 人中 153 人。Harada ら 2025）
  - 壁：「職場に設備がない」「使い方がわからない」
- 原稿：
  > 「病気やけがで、指が握った形のまま固まってしまう人がいます。そうなると、筆やペン、スプーンを自分で持つことが難しくなります。
  > 道具を持つための『自助具』は、手の形が人それぞれなので、一人ひとりに合わせて作る必要があります。3D プリンタなら作れますが、作業療法士の調査では、3D プリンタを使ったことがある人は 4.4% だけでした。理由は『職場に設備がない』『使い方がわからない』です。」

### スライド 3：解決（20 秒）

- 画面：横一列の流れ図
  `こぶしを撮る（＋1円玉）` → `手の 3D（mm）` → `AI が部品と寸法を決める` → `OT が確認` → `3D プリント`
- 原稿：
  > 「私たちのアプリでは、1 円玉と一緒にこぶしを動画で撮るだけで、手の形を mm 単位の 3D にします。そこからこぶしにかぶせるカバーと、筆を挟むクリップを AI が組み立て、作業療法士が確認して、3D プリントします。」

### スライド 4：デモ動画（75 秒）

- 画面：動画だけ（全画面）。動画の中身は §2 の絵コンテ
- 原稿（動画に合わせて話す）：
  > 「まず、やりたいことを選びます。今回は『筆で字を書きたい』、筆の太さは 8mm です。
  > 次に、1 円玉を横に置いて、こぶしをスマホで半周撮ります。手の骨組みが重なって、写っているかがその場でわかります。1 円玉は自動で見つかります。
  > 撮った動画から、手の 3D ができました。大きさは 1 円玉で mm に合わせています。
  > ボタンを押すと、Gemini が部品を選んで寸法を決めます。カバーは手の面に沿って作られ、筆を挟むクリップの角度も、決めた理由と一緒に出てきます。角度はここで選び直せます。
  > 最後に、印刷用のデータをダウンロードします。こうして刷ったのが、こちらです。」
  （最後の一文で、実物を手に持って見せる）

### スライド 5：仕組みと Google 技術（35 秒）

- 画面：構成図（ブラウザ／Cloud Run／Cloud Run GPU／Gemini／Firebase）。各技術の横に「何のために」を 1 行
  - MediaPipe：ブラウザの中で手の 21 点を取る → 動画を外に送らない
  - Gemini 4 Argon：部品選び・寸法・理由・画像での確認を 1 つのモデルで
  - Cloud Run：OpenSCAD をコンテナで動かす。手の 3D 復元は GPU（L4）で、使わない間は 0 台
  - Firebase：ルールで「OT が確認するまで印刷データを渡さない」を守る
- 原稿：
  > 「仕組みです。手の点は MediaPipe でブラウザの中で取るので、動画はサーバーに送りません。手の 3D は Cloud Run の GPU で作ります。
  > Gemini には形そのものは作らせず、人が作って試し刷りした部品の中から選ばせ、寸法と理由を JSON で出させます。それを Cloud Run の OpenSCAD で形にし、できた形を Gemini が画像で見て確かめます。
  > 作業療法士の確認が済むまで印刷データを渡さないことは、Firebase のルールで守っています。」

### スライド 6：安全・プライバシーと先行研究との違い（35 秒）

- 画面：左右 2 列
  - 左「安全」：手のひら側は開ける／手首を覆わない／角は丸く・壁は 2mm 以上／描いたあとに自動で検査／OT が確認
  - 右「先行研究との違い」：ASSETS 2025（Georgia Tech）の課題「正確な寸法を指定できない」「臨床家が安全性を心配」→ 本作は「測った mm から寸法を決める」「理由を見せて OT が確認」
- 原稿：
  > 「安全のため、カバーは『かぶせるだけ』にしました。指を無理に開かせず、手のひら側は開け、手首は覆いません。これは AI ではなく、描いたあとの形をプログラムで検査しています。
  > 生成 AI で自助具を作る先行研究では、正確な寸法を指定できないことと、臨床家が安全性を心配することが課題でした。私たちは、測った寸法から形を決め、理由を見せて、作業療法士が確かめる流れで、この課題に答えます。」

### スライド 7：実物と結果・これから（25 秒）

- 画面：刷ったカバーとクリップの写真、着けている写真。数字「採寸の誤差 ○mm」（11/9 の検証の値）。これから：ペン・スプーンのクリップ、スマホアプリ化
- 原稿：
  > 「実際に刷って、メンバーの手で確かめました。採寸の誤差は ○mm でした。
  > これからは、ペンやスプーンのクリップを増やし、実際に指が固まった方と作業療法士の方に使ってもらいたいと考えています。ありがとうございました。」

## 2. デモ動画の絵コンテ（75 秒）

| 秒 | 画面 | 見せたいこと | 撮り方のメモ |
|---|---|---|---|
| 0–8 | S2 やりたいこと | 「筆で字を書きたい」「筆の太さ 8mm」を選ぶ | タップを速めに。待ち時間は切る |
| 8–25 | S3 撮影 | 1 円玉を置き、こぶしを半周撮る。骨組みが重なる | スマホの画面録画と、外から撮った映像を左右に並べると伝わりやすい |
| 25–30 | S4 1円玉の確認 | 1 円玉が自動で囲まれる | |
| 30–40 | S5 採寸結果 | 手の 3D が回る。mm の数字 | 解析の待ち時間は早送り（「早送り」と字幕を出す） |

- 解像度は 1920×1080。文字が小さい画面はズームする
- 撮影は `settings/runtime.demo_mode = true` の間に行う
